# Truvidence Website V2

A five-page Bootstrap 5 website adapted from the Nexora theme layout language, using the approved Truvidence content hierarchy.

## Pages
- `index.html` — Home
- `services.html` — Services
- `approach.html` — Our Approach
- `about.html` — About
- `contact.html` — Contact

## Design system
- Headings/UI: Open Sans
- Body: Roboto
- Brand palette: Truvidence V2 with darker functional variants for contrast
- Icons: Font Awesome 7.3.0
- Framework: Bootstrap 5.3.3
- Local visuals are in `img/`

Open `index.html` to preview.
